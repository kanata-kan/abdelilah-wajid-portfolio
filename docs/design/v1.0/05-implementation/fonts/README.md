# Frozen UI font files

Inter for English, IBM Plex Sans Arabic for Arabic. These are explicit implementation selections made in the 2026-09-08 handoff; the generated mockups did not identify their fonts. The brand wordmark is outlined SVG artwork and does not use either family.

Official font source: [Inter](https://github.com/google/fonts/tree/main/ofl/inter) and [IBM Plex Sans Arabic](https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic). Retrieved 2026-09-08. Original TTF files and each family’s OFL license are included. WOFF2 files are web-container conversions of these exact fonts. The file manifest pins the delivered binaries; do not silently substitute a newer release or a CDN font.

Weights used: 400, 500, 600, 700. No artificial Arabic letter spacing. No italic text in this homepage. Use the provided fonts.css, self-host the files and wait for document.fonts.ready before visual comparison.
